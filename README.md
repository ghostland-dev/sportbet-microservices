# BetSport

Sports betting front-end prototype in vanilla JavaScript.

## Features

- Match listing and odds
- Bet slip logic in plain JS

## Tech Stack

- HTML/CSS

## Getting Started

```bash
git clone https://github.com/ghostland-dev/sportbet-microservices.git
cd sportbet-microservices
# open index.html in your browser, or serve the folder:
npx serve .
```
